— pour les curieux

Auto-héberger en trois commandes.

Il te faut Docker et Node. Le guide complet est dans le dépôt.

# récupérer le projet
git clone https://github.com/Ulrichfr/Vignette-App.git && cd Vignette-App

# générer les secrets puis lancer la stack (Postgres, auth, realtime, Caddy)
node supabase/scripts/gen-env.mjs
docker compose -f supabase/docker-compose.yml up -d

# appliquer le schéma et construire la web app
./supabase/scripts/apply-migrations.sh
pnpm install && pnpm build
en attendant les apps natives…

La web app t'attend.
